# Vectors

`lomboklog-vectors-v1.json` is the cross-language test contract for LombokLog.

- SHA-256: `fa679022004b8d05f6ca234b8e3f28af129d8c9acb77a5dc168a72f9de1fccc0` (must equal the hash in `docs/SPEC_LombokLog_v0.1.0.md`).
- Generated by `scripts/gen-vectors.mjs`. Group `golden`: expectations are written by hand and matched against the TypeScript port during generation (a mismatch fails the generation). Group `generated-regression`: seeded random records, with expectations from the TypeScript port confirmed by the Rust port.
- Every case calls the function `fn` with `args`; `expect` has the form `{ "result": ... }` or `{ "error": code }`.
- Every claimed port MUST run every case.
- Count: 290 cases (200 golden cases with hand-written expectations, 90 generated regression cases).
